SHOCKRIDE GARAGE — WEBSITE TOKO ONLINE PEMENDEK & PENAIK SHOCK

Isi folder:
- index.html : seluruh kode HTML, CSS, dan JavaScript.
- assets/ : 4 foto ilustrasi produk komponen shock.

CARA MENJALANKAN TANPA LARAGON
1. Ekstrak file ZIP.
2. Buka folder shockride_store.
3. Klik dua kali index.html. Website akan terbuka di Chrome/Edge.
   Internet tidak dibutuhkan untuk melihat tampilan lokal.

SEBELUM DIPUBLIKASIKAN
1. Buka index.html dengan VS Code atau Notepad.
2. Cari WHATSAPP_NUMBER = "6281234567890", lalu ganti dengan nomor toko.
3. Foto produk saat ini adalah foto ilustrasi komponen/aksesori. Ganti file di folder assets dengan foto produk asli, nama file tetap sama.
4. Ubah nama toko, detail produk, kompatibilitas, harga, alamat, jam operasional, dan legalitas sesuai data usaha.
5. Jangan menganggap foto ilustrasi sebagai foto produk/part yang pasti cocok untuk motor tertentu. Konfirmasi ukuran dan kecocokan dengan mekanik/pemasok.

FITUR
- Hero dan navigasi
- Kategori pemendek/penaik dan atas/bawah
- Pencarian produk dan urut nama
- 8 kartu produk
- Keranjang dengan tambah/kurangi jumlah
- Checkout dan formulir kontak melalui WhatsApp
- Ulasan tersimpan di browser (localStorage)
- Cerita toko, panduan pemilihan, kebijakan, transaksi, dan identitas usaha
- Responsive untuk HP dan laptop

CATATAN
Keranjang dan ulasan bekerja di browser. Website belum memiliki database/server, login pelanggan, stok real-time, atau payment gateway.
